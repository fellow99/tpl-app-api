## 一、说明

## 三、测试策略

### 3.1 API 接口测试

| 测试维度 | 说明 |
|---------|------|
| **正常流程** | 各接口在正确参数下的正常响应 |
| **参数校验** | 必填字段缺失、格式错误、边界值 |
| **鉴权验证** | 无 Token、过期 Token、错误 Token |
| **业务规则** | 用户名唯一性、密码正确性、账号状态 |
| **验证码** | 过期、错误、大小写、重复使用 |

### 3.2 当前测试覆盖

⚠️ 当前代码库 **不包含任何自动化测试代码**。测试用例文档为功能测试指引，供手动测试或后续自动化测试框架实施参考。

## 四、与前端工程的测试关联

前端工程 `tpl-app-web`（`..\tpl-app-web\`）可能包含：
- E2E 测试（Playwright / Cypress）
- 组件测试（Vitest）
- 接口联调测试

前端测试用例应与本 API 的测试用例保持对应关系（如登录流程的 API 测试 + E2E 测试覆盖同一业务场景）。
